# Qarai Guard

Qarai Guard is a text classification model for identifying unsafe content. This repository includes the model inference script and notebooks for training, evaluation, and data preparation.

## Available models

| Model ID | Size | Macro F1 score |
|---|---:|---:|
| [Qarai/qarai-guard-163M-v0](https://huggingface.co/Qarai/qarai-guard-163M-v0) | 163M | 94.72 |
